# Fashion outfit datasets for recommendation

Processing scripts for fashion outfit datasets. The processed data (item images, pre-extracted ResNet-34 features, and outfit tuple splits) is released on [Hugging Face](https://huggingface.co/datasets/lzcn/outfit-datasets) and can be used directly without any preprocessing:

```bash
git clone https://huggingface.co/datasets/lzcn/outfit-datasets data
```

Large files use Git LFS; `lock.mdb` files are auto-generated by LMDB and can be ignored.

## Datasets

| Folder | Dataset | Scripts |
| --- | --- | --- |
| `polyvore-u/` | PolyVore-U (personalized) | convert raw outfits (`data_processing.ipynb`), build image/feature LMDB (`create_image_lmdb.py`, `create_feature_lmdb.py`) |
| `iqon-3000/` | IQON3000 (personalized) | download (`downloader.py`), build labels (`merge_json.py`, `create_label_files.py`), build image/feature LMDB (`create_lmdb.py`, `extract_features.py`) |
| `maryland-polyvore/` | Maryland-PolyVore | build image LMDB, tuples and word embeddings |
| `polyvore-outfits/` | PolyVore (UIUC) | extract visual/semantic features, build disjoint/non-disjoint tuples |
| `ifashion/` | iFashion | download and process (see folder README for the raw format) |
| `polyvore-180/` | PolyVore-180 | build image LMDB, tuples and HFGN graph files |
| `shift15m/` | Shift15M | download, process and build the feature LMDB |

Each folder is self-contained: download the raw dataset from its official source, then run the scripts in order.

## Tuple Format

Each split stores one outfit per line:

```
uidx,size,item_1,...,item_K,type_1,...,type_K
```

padded with `-1` to a fixed number of slots `K`.
